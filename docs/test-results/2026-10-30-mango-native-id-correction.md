## Installed public callback analysis and patch

Read-only inspection of the installed **system APK**, SHA25670ddf145561e270a013cb1c75f32d7792ef123aa0bdca568c466608926a0f961, with Android SDK apkanalyzer explains the mismatch. MediaBrowsableProvider emits one-based row suffixes in its All Music, Now Playing and nested Album browser IDs, but its playback callback returns the numeric suffix unchanged. MusicService's callback uses that number directly as a zero-based list index. The public Album ID2 therefore selects entry3. Album/artist/genre context numbers are handled separately by the source and must stay unchanged. No Mango/private music database, Apple download, firmware modification or root access was used; no APK or disassembled implementation is published.
