## Per-selection procedure and evidence

scripts/check-mango-listening-selection.ps1 takes one explicit Sequence, never a batch playback loop. It requires Apple paused, pauses only the preceding Mango clip, checks the unchanged reported volume/offline state, re-browses every storage/folder label with fresh opaque IDs and exact breadcrumbs, finds one exact playable filename, checks that public file's bounded container header and sends PLAY_ITEM once. It then observes matching Mango title/playing with Apple paused. A complete embedded title tag within the bounded prefix is used when available; otherwise the expected title remains a filename-derived hypothesis. A mismatch stops the attempt without replay. Successful source state and actual human listening are separate requirements. Filename/folder identity, app/package hashes, raw source reports, helper hashes and timestamps are retained per attempt under artifacts/mango-listening/.

The helper was corrected to use complete embedded ID3/Vorbis title fields when present, without reading artwork/whole tags or changing the source adapter. The earlier clip naturally advanced during diagnosis. An explicit new selection5 with fresh UI IDs was then made using the verified title; the first failed attempt is retained separately. This is a diagnostic filename/tag-assumption correction, not an application playback fix or a clean20-attempt run. No old protocol command was replayed automatically.

scripts/record-mango-listening-confirmation.ps1 accepts only an actual human answer for a pending selected/state/header-verified attempt. It sends no device command. Delayed reports do not prove instantaneous metadata/audio alignment or full-track playback; natural queue advancement can occur before processing an answer. scripts/summarize-mango-listening.py aggregates the stored reports and retains failed attempts/pending answers instead of converting them into successes. All21 per-selection results, including the failed verification attempt, are listed below; raw artifacts remain excluded from Git.
